# 语音能力补全对照

基线：鲸记账 v1.5.7 / `12386eabc4a05537b74d8d07081be0aaf16000b0`。
规则来源：拾光账本 v3.1.4 / `49aeabcaf149ed7b22d64c670e933077bfde0549`。

| 能力 | 实现与保留策略 | 验证 |
| --- | --- | --- |
| 外观与手势 | 沿用鲸记账的配色、字体、布局、键盘、备注选择器、上滑入口 | CI 从 v1.5.7 源码生成浅/深色首页、手动页、语音待录音与核对页共8张420×900图（仓库原有手机预览画幅），再逐像素比较 |
| 语音拆分 | 移植3.1.4本地核心规则，经适配器映射现有分类ID | 原版金额/日期/否定/用途规则测试；鲸记账原测试继续执行 |
| 历史备注 | 逐备注、逐分类的次数与最新日期，区分收支，最长商家和括号分店名 | 盒马、多分类、220条以上历史、收入与支出隔离 |
| 解析优先级 | 指定分类 > 本次明确用途 > 历史备注 > 通用词；歧义显示候选 | 商家买纸巾、买冰箱、分类购物与历史冲突 |
| 特色 | 保留波形、短自动备注、原文420ms自动重拆分、额外用途词及财务大写数字 | 剧本杀、寄件、清洁、幼儿园、角分、全角数字 |
| 日期 | 日期更正、冲突、非法日期和支付/物品日期区分；从首页传递至确认页 | 中文逐位年份、闰年、跨年、星期冲突、语音保存 |
| 手改字段 | 重拆分保留金额/日期/类别/备注/收支，手改类型会重新推荐合法类别 | 类型/备注override与异步结果代次保护 |
| 录音与预热 | 前台预热合并单例，采集独立于模型，松手先停麦 | 冷模型录音并行、重复预热合并、权限迟到取消 |
| 资源回收 | 后台15秒/可配置、不因hidden→paused延期；回前台校验真实时间；低内存优先释放 | 后台快速返回、延迟计时器、关闭保留、低内存、取消解码 |
| 模型打包 | 原生64KiB流式复制，模型与词表精确大小，CI锁定SHA256 | APK内227330205字节INT8、75354字节词表、ARM64库、真实中文推理 |
| 签名 | 使用目标仓库现有密钥，不复制其他App的密钥 | 比对v1.5.7自动发布包证书；V1/V2/V3和下载SHA256校验 |

代码准备不代表测试已通过；以新增release流水线实际结果为准。CI若失败不会发布Release。
