# 鲸记账 v1.5.8

在 1.5.7 美化界面上补齐拾光账本 3.1.4 的语音能力，保留波形动画、滑选入口、原文自动重拆分和扩展词库。

- 完整历史备注按收支、分类、次数和最近日期匹配；支持分店名和较长商家名优先。明确口述分类、本次实际用途优先；歧义时提示候选分类。
- 日期支持中文年份、相对日期、星期与绝对日期冲突、更正和无效日期提示；首页语音后的确认页正确保留识别日期。
- 显式备注中的数量、日期、工资词不污染交易字段；多金额没有总额时要求手动核对；保留手改金额、分类、日期、类型和备注。
- 录音与模型准备并行、前台共享模型、后台默认保留15秒（可关闭或选5/10/15/30秒）、低内存释放。补齐取消、权限等待、后台切换时的过期结果保护。
- 模型采用原生分块复制，推理与大备注库解析在独立 isolate 执行；增加静音、过短录音检查。
- 完整打包 Paraformer-zh INT8、词表、授权及 ARM64 推理库。沿用本仓库 v1.5.7 自动发布包的固定签名。

未修改配色、字体、主要布局、记账键盘、备注选择器或滑选手势。CI 对照 v1.5.7 生成浅色/深色界面基准，比较首页、手动面板、语音待录音及核对面板；同时执行规则、生命周期和真实模型推理测试。

Android ARM64 安装包：`whale-ledger-v1.5.8-arm64.apk`。此版未更新在线网页版。
